01Fundamentos: regla, selector, propiedad y valor

Regla CSS

Una regla selecciona uno o varios elementos y les aplica declaraciones.

¿Para qué sirve? Es la unidad básica de CSS.
.tarjeta {
  color: #0f172a;
  padding: 16px;
}
La parte antes de { } es el selector; dentro van propiedad y valor.
Así se veVISTA
La regla da espacio interno y cambia el color del texto.
Soy una .tarjeta con padding.

Selector

Indica exactamente qué elementos recibirán los estilos.

¿Para qué sirve? Puedes apuntar a etiquetas, clases, ids, atributos o combinaciones.
p { color: #475569; }
.destacado { color: #be123c; }
#principal { font-weight: 800; }
En Angular se prefieren clases para estilos reutilizables.
Así se veVISTA
Solo el párrafo con la clase destacado cambia de color.

Texto normal

Texto seleccionado por .destacado

Propiedad y valor

La propiedad dice qué se cambia; el valor indica cómo.

Ejemplo: font-size es la propiedad y 20px es el valor.
color: #dd0031;
font-size: 20px;
border-radius: 12px;
Así se veVISTA
Propiedad + valor = cambio visible

Clase . e ID #

Una clase es reutilizable; un id identifica normalmente un elemento único.

¿Para qué sirve? La clase es la opción habitual para dar estilos a componentes.
.boton { padding: 10px; }
#guardar { font-weight: 800; }

02Layout: Box Model, Flexbox, Grid y responsive

Box Model

Todo elemento se puede pensar como contenido + padding + border + margin.

¿Para qué sirve? Explica por qué una tarjeta ocupa el espacio que ocupa.
.caja {
  padding: 18px;
  border: 9px solid #fca5a5;
  margin: 10px;
}
Así se veVISTA
contenido

Flexbox

Alinea y distribuye elementos principalmente en una dirección.

¿Para qué sirve? Navbar, botones en fila, alineación de tarjetas y encabezados.
.fila {
  display: flex;
  gap: 8px;
  justify-content: space-between;
}
Así se veVISTA

CSS Grid

Organiza contenido en filas y columnas.

¿Para qué sirve? Dashboards, galerías y layouts con varias columnas.
.grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 8px;
}

@media y responsive

Permite adaptar el diseño a distintos tamaños de pantalla.

¿Para qué sirve? Evita que una interfaz pensada para escritorio se rompa en móvil.
@media (max-width: 700px) {
  .grid { grid-template-columns: 1fr; }
}

03Interacción, url() y CSS dentro de Angular

:hover y :focus-visible

Son pseudoclases: aplican estilos solo cuando ocurre un estado.

¿Para qué sirve? Dan feedback visual al mouse y al teclado.
button:hover { transform: translateY(-3px); }
input:focus-visible { outline: 3px solid #93c5fd; }
Así se veINTERACTÚA

url(...)

Es una función CSS que referencia un recurso, por ejemplo una imagen o una fuente.

¿Para qué sirve? Se usa mucho en background-image. La ruta puede ser relativa, absoluta o un data URI.
.hero {
  background-image: url('/assets/fondo.svg');
}
No confundir url() de CSS con templateUrl o styleUrl de @Component.
Así se veVISTA

CSS global vs CSS del componente

Angular permite reglas globales y estilos asociados a una pieza específica.

Regla práctica: global para tipografía/tema; componente para la apariencia de esa pieza.
src/styles.css
src/app/components/tarjeta/tarjeta.component.css
Así se organizaARCHIVOS
src/styles.cssbody, variables, tipografía
tarjeta.component.csssolo la tarjeta

Encapsulación de estilos

Por defecto Angular evita que los estilos de un componente se filtren libremente a todos los demás.

¿Para qué sirve? Mantiene cada componente más predecible. También existen ViewEncapsulation.None y ShadowDom.
@Component({
  styleUrl: './tarjeta.component.css'
})
